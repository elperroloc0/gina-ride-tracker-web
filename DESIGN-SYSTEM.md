# Gina Ride Tracker — дизайн-система

Визуальный язык взят с сайта ginasgymnastics.com, чтобы приложение читалось как часть
того же бренда: электрик-синий, почти-чёрный, светло-серый фон, крупный жирный uppercase,
pill-кнопки, волнистые разделители секций.

Источник правды по внешнему виду — артборды в этой папке (`Main`, `Children`, `Routes`,
`ParentLive`, `ParentIdle`, `ParentLogin` `.dc.html`). Этот файл описывает значения,
которые в них использованы, чтобы фронтенд не пересобирал их на глаз.

с пунктирной обводкой `stroke-dasharray: 7 6`.

Правило: `--alert` — только про действие оператора, не про «плохо выглядит».
Красный из палитры сайта намеренно не используется как декоративный акцент.

## Типографика

Обе гарнитуры — Google Fonts, подключаются одним `<link>`.

```
display: 'Archivo Black', 'Helvetica Neue', Helvetica, Arial, sans-serif
body:    'Archivo', 'Helvetica Neue', Helvetica, Arial, sans-serif
```

Fallback подобран метрически близким: PDF/PNG-экспорт не вшивает Google Fonts,
поэтому заголовки верстаются с запасом ~10 % по ширине.

| Роль | Размер / начертание | Детали |
| --- | --- | --- |
| Hero (экран входа) | Archivo Black 40 / line-height 0.98 | uppercase, `letter-spacing: -0.03em` |
| Экранный заголовок (мобильный) | Archivo Black 30–34 / 1.02–1.05 | uppercase, `-0.025em` |
| Заголовок раздела (десктоп) | Archivo Black 30 | uppercase, `-0.02em` |
| Заголовок карточки | Archivo Black 19–27 | `-0.015…-0.02em`, uppercase только в цветных блоках |
| Caps-метка секции | Archivo 11 / 700 | uppercase, `letter-spacing: 0.1em`, цвет `--muted` |
| Основной текст | Archivo 13–15 / 400–500 | 14–15 на мобильном, 13 в плотных таблицах |
| Строка таблицы | Archivo 13–14 / 600 для имени, 13 / 400 для остального | |
| Подпись | Archivo 12 / 400, цвет `--muted` | |
| Микро-бейдж | Archivo 10–11 / 700 | uppercase, `letter-spacing: 0.05em` |

Время, координаты, IMEI, идентификаторы — всегда `font-variant-numeric: tabular-nums`,
иначе колонки времени в таблице «дрожат».

Длинные заголовки — с `text-wrap: pretty`.

## Форма и ритм

**Радиусы**

- `999px` — кнопки, бейджи, чипы-статусы, тумблеры, поисковое поле, селектор ребёнка
- `16px` — карточки мобильного приложения
- `14px` — карточки и панели консоли, контейнер карты
- `12px` — поля ввода, иконка-плитка 40×40
- `10–11px` — строки внутри карточки (день расписания, элемент списка геозон)
- `8–9px` — чип дня недели (30 px), кнопки зума карты
- `6px` — чип дня недели в таблице (22 px)

**Отступы**

- Поля экрана: 20 px в консоли, 16 px в мобильном приложении
- Внутри карточки: 16–20 px (десктоп), 16–18 px (мобильный)
- Шаг сетки: 8 / 10 / 12 / 14 / 16 / 20 — межблочные `gap`, не margin на элементах

**Разметка** — только flex и grid с `gap`. Никаких пробельных текстовых узлов и
per-element margin для расстановки соседей: это ломается при перетаскивании в редакторе.

## Размеры контролов

| Элемент | Десктоп | Мобильный |
| --- | --- | --- |
| Топбар | 64 px | шапка с волной, ~207–268 px |
| Основная кнопка | 42–44 px (`padding: 12px 20px`), 13 px / 700 | 52–54 px, 14–15 px / 700 |
| Вторичная кнопка | контур 1.5 px `--line`, тот же размер | то же |
| Поле ввода | 40–42 px, 13 px | 52 px, 15 px |
| Строка таблицы | 62 px; шапка 44 px; футер 46 px | — |
| Тумблер | 34×20 (в списке), 40×23 (в форме) | — |
| Аватар-кружок | 30 / 32 / 46 px | 24 / 38 px |
| Чип дня недели | 22 px (таблица) | 30 px (карточка) |

Минимальный тап-таргет на мобильном — 44 px. Селектор ребёнка, кнопки и поля

**Иконки** — только inline SVG, обводкой, `stroke-width: 1.7–1.9`, сетка 16/20/24.
Эмодзи в интерфейсе не используются: бренд их не использует, и они не перекрашиваются.

## Повторяющиеся паттерны

**Волна-разделитель** — фирменный элемент сайта. Абсолютно позиционированный SVG на
нижней кромке цветной секции, `preserveAspectRatio="none"`, высота 26–30 px, заливка —
цвет *следующей* секции:

```html
<svg viewBox="0 0 390 26" preserveAspectRatio="none" style="...position:absolute;bottom:-1px">
  <path d="M0 14C60 0 120 0 195 9s135 17 195 3v14H0z" fill="#F5F5F2"/>
</svg>
```

Применяется в шапках родительских экранов. В консоли оператора не используется —
там она мешает плотной сетке.

**Статус-бейдж** — pill 5×11 px, 11 px / 700, uppercase, `letter-spacing: 0.05em`.
Синий-заливка = происходит сейчас (`On ride`, `Running`); серый = запланировано;
`--alert-tint` = требует действия.

**Чипы дней недели** — пять квадратов M T W T F подряд, `gap: 3–4px`; активный день
залит `--blue` с белой буквой, неактивный — `--fill` с `--muted-2`. Рядом — время
забора табличными цифрами. Это визуальное представление `ChildSchedule`.

**Вертикальный таймлайн поездки** (мобильный) — колонка 20 px: пройденный шаг —
залитый кружок с галочкой, текущий — кольцо 5 px, будущий — контур `--line-off` 2 px;
между шагами линия 2 px (пройденная — `--blue`, будущая — `--line`).

**Точка живости** — 7 px кружок `--ok` рядом с названием сервиса. Используется только
там, где состояние реально приходит с бэкенда.

## Связь с моделями бэкенда

| Экран | Данные |
| --- | --- |
| Live map | WebSocket `ws/van/` (позиция), `fleet.Van`, `fleet.GeoFence`, `tracking.ArrivalEvent` |
| Карточка активной поездки | `ArrivalEvent` (ENTER на origin) + `accounts.Child.active_ride` / `active_ride_start` |
| Children | `accounts.Child`, `accounts.ChildSchedule`, `accounts.User` (родитель, `phone_number`) |
| Routes & zones | `fleet.Route`, `fleet.GeoFence` (`latitude`, `longitude`, `radius`, `traccar_id`, `is_active`) |
| Parent live | тот же WebSocket, но подписка открыта только пока `active_ride=True` |
| Parent idle | `ChildSchedule` (ближайшая поездка) + история `ArrivalEvent` |

Оператор видит на маршруте всех детей, чьё расписание совпало по дню и окну —
поимённой явки в системе нет и не планируется (см. `architecture-plan.md`).

## Тон и копирайт

Язык интерфейса — английский, как на сайте (у сайта есть переключатель EN/ES —
испанская локализация вероятна и её стоит закладывать).

Родителю пишем короткими человеческими фразами о ребёнке, а не о технике:
«Picked up at Coral Way K-8», «You'll get a text the moment she's there».
Оператору — точные факты: время, зона, сколько родителей уведомлено.

Никаких выдуманных цифр: имена, школы, телефоны, IMEI и координаты в макетах —
образцы и подлежат замене. Реальные данные с сайта только два: адрес зала
(4057 SW 152nd Ave, Miami, FL 33185) и телефон 1 (305) 456-4150.
